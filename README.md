# Reprise Haut du Corps

Programme haut du corps sur 8 semaines (+ cycle 2), adapté au genou, avec chrono de séance.
Site statique servi par Netlify : https://reprise-haut-du-corps.netlify.app

- `index.html` : toute l'appli (HTML, CSS, JS dans un seul fichier)
- `manifest.webmanifest`, `sw.js`, icônes : installation sur l'écran d'accueil et usage hors ligne
- `netlify.toml` : pas de build, publication du dossier tel quel
